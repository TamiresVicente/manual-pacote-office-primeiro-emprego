Manual Prático de Introdução ao Pacote Office

Projeto de Atividade Extensionista do curso de Análise e Desenvolvimento de Sistemas – UNINTER.

O projeto tem como objetivo disponibilizar gratuitamente um material introdutório sobre Microsoft Word, Excel e PowerPoint, com foco em inclusão digital e preparação para o mercado de trabalho.

Público-alvo: usuários iniciantes e pessoas em busca do primeiro emprego.

Local de aplicação inicial: Osasco – SP.
